## 2. normal_type and filter 6
`normal_type` = "tumour-adjacent tissue, same surgical specimen". Adjacent tissue usually contains infiltrating tumour cells, so true somatic variants can show normal alt reads. Filter 6 (normal alt >= 3 and 0.02 <= normal_vaf < 0.20) assumes a clean normal where such reads mean an artifact, so it may reject real somatic variants here. chr12:8203311 is a possible example (tumour VAF 0.15, normal VAF 0.05 with 4 alt reads, af_used 2e-5): the normal signal is one third of the tumour signal, which fits tumour cells in the adjacent tissue as well as a technical artifact. Filter 4 uses a similar normal_vaf cut (>= 0.20) and could in principle remove a high-VAF clonal somatic variant that has leaked into the adjacent normal. In this dataset no site looks like that: all three germline calls (chr3:2655410, chr7:5120055, chr7:5350700 C>G) have a normal VAF above their tumour VAF, which fits true germline variants and not tumour cells in the normal. Tradeoff: replacing the fixed 0.02 to 0.20 band with a ratio to the tumour VAF (illustrative, not validated: normal_vaf < 0.5 x tumour VAF) would keep chr12:8203311 (0.05 vs 0.15) while still removing sites where the normal VAF is close to or above the tumour VAF, but it lets more low-level germline variants and normal-borne artifacts through. A blood normal would remove the problem and allow a stricter rule.

## 3. Threshold evaluation
- **Admits an invalid variant:** filter 9 requires alt_count >= 10. chr3:2800119 T>C has 9 alt reads, all forward (strand_balance 0), sits in an annotated repeat (unit 4, 3 units), and still passes. It is an SNV, so filter 12 (indels only) never applies. Lowering the gate to alt_count >= 5, or using a binomial strand test, would catch it.
- **Rejects a variant that may be a real somatic call:** filter 7 on chr17:7577120 C>T. The germline resource gives af 0.47, so expected_contam_alt = 0.045 x 320 x 0.47 = 6.77 and the 9 alt reads fall below 2 x 6.77 = 13.5. But the normal has 0 of 90 alt reads, which argues against a germline het, so the 0.47 value itself looks suspect (the same 0.47 is also given to chr17:7577538 G>C, a different allele). This cannot be proven from the files alone, but a contamination test that also looked at the normal would not reject this site. Its tumour VAF is only 2.8%, so it is also close to the detection limit.
